# Elementa — Interactive Periodic Table

Elementa is a modern interactive periodic table web application built with HTML, CSS and JavaScript.

## Features

- Explore all 118 chemical elements
- Search by element name
- Search by chemical symbol
- Search by atomic number
- Filter elements by category
- Random element button
- Interactive element details
- Dark and light themes
- Responsive mobile design
- Progressive Web App support
- Offline caching through a service worker

## Element Categories

Elementa includes:

- Alkali Metals
- Alkaline Earth Metals
- Transition Metals
- Post-Transition Metals
- Metalloids
- Nonmetals
- Halogens
- Noble Gases
- Lanthanides
- Actinides
